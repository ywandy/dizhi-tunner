# 功能 PRD：从数字谱编排编辑器

## 1. 功能目标

让用户输入数字谱，选择曲谱调、笛子调和筒音指法，系统实时生成竹笛洞洞谱，并支持保存、打开恢复和导出。

该模式中：

```text
数字谱文本 = 源内容
洞洞谱结果 = 根据配置实时计算出的结果
```

## 2. 依赖能力

| 依赖 | 用途 |
|---|---|
| SavedScore 数据模型 | 保存和恢复乐谱 |
| 本地乐谱库 | 新建、更新、打开 |
| 洞洞谱指法数据与展示 | 展示转换结果 |
| 数字谱解析与转换引擎 | 实时生成 `holeScore` |
| 编辑状态与安全保护 | dirty、返回、打开前提醒 |

## 3. 页面结构

```text
从数字谱编排

乐谱名称：
[小星星________]

配置：
曲谱调：[G]
笛子调：[G 调笛]
筒音：[筒音作5]

数字谱输入：
[多行输入框]

简谱键盘：
低  .1 .2 .3 .4 .5 .6 .7
中   1  2  3  4  5  6  7
高  1' 2' 3' 4' 5' 6' 7'
符   #  b  0  -  |
辑   空格  换行  删除  清空

转换结果：
- 简谱音
- 真实音高
- 洞洞谱
- 指法备注
- 警告和错误

操作：
[保存] [导出 JSON] [返回]
```

## 4. 默认值

| 字段 | 默认值 |
|---|---|
| 标题 | 空 |
| 曲谱调 | 沿用当前 app 默认调 D |
| 笛子调 | 当前偏好中的 `diziKey`，没有则 D |
| 筒音指法 | 当前偏好中的 `fingeringProfileId`，没有则 `tube_as_5` |
| 数字谱内容 | 空 |

建议第一版沿用当前调音器偏好作为笛子调和筒音指法默认值，曲谱调使用当前 app 默认调 D，减少用户重复选择。

## 5. 简谱键盘

### 5.1 插入规则

点击音符后，在光标位置插入 token 并自动追加空格：

| 按钮 | 插入 |
|---|---|
| `1` | `1 ` |
| `.5` | `.5 ` |
| `5'` | `5' ` |
| `-` | `- ` |
| `|` | `| ` |

### 5.2 升降号规则

```text
点 # 后，# 进入待组合状态
再点 4，插入 "#4 "
插入后状态清空

点 b 后，b 进入待组合状态
再点 7，插入 "b7 "
插入后状态清空
```

如果用户点了 `#` 后又点休止、延音、小节线或编辑按钮，待组合状态应取消。

### 5.3 删除规则

删除光标前一个完整 token，而不是删除单个字符。

示例：

```text
当前输入：1 2 #4 5'
点击删除：1 2 #4
再次删除：1 2
```

## 6. 实时转换

以下内容变化时自动重新计算：

- 数字谱内容
- 曲谱调
- 笛子调
- 筒音指法

页面不需要“开始转换”按钮。

## 7. 结果展示

普通音：

```text
简谱：1
音高：G5
洞洞：●●●○○○
备注：中音1
```

休止：

```text
简谱：0
备注：休止
```

延音：

```text
简谱：-
备注：延音
```

小节线：

```text
|
```

错误项需要就地展示，不要只在顶部弹一个总错误。

## 8. 保存规则

保存时写入完整 `SavedScore`：

```ts
{
  mode: 'jianpu-generated',
  config: {
    scoreKey,
    fluteKey,
    fingeringProfileId,
  },
  source: {
    kind: 'jianpu',
    text,
  },
  holeScore,
}
```

保存后：

- 新乐谱设置 `currentScoreId`。
- 旧乐谱更新原 id。
- `dirty = false`。
- 给出“已保存”或“已更新”反馈。

## 9. 返回规则

点击返回：

- 如果 `dirty = false`，直接回洞洞谱首页。
- 如果 `dirty = true`，按“编辑状态与安全保护”PRD 处理。

## 10. 非目标

- 不编辑复杂节奏。
- 不支持多声部。
- 不支持拖拽排序转换结果。
- 不支持直接修改转换结果里的洞洞图。需要修改特殊指法时，引导后续使用手动编排。

## 11. 验收标准

1. 可以输入数字谱文本。
2. 可以通过简谱键盘插入低、中、高音 token。
3. 可以通过 `#` / `b` 组合输入升降音。
4. 删除按钮能删除一个完整 token。
5. 修改输入或配置后，转换结果实时刷新。
6. 结果卡片展示简谱、音高、洞洞图和备注。
7. 错误 token 和超范围音有友好提示。
8. 保存后乐谱出现在本地乐谱库。
9. 打开已保存数字谱乐谱后，标题、配置、文本和结果都能恢复。
