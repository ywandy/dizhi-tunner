# 功能 PRD：手动洞洞谱编排编辑器

## 1. 功能目标

让用户不输入数字谱，直接通过指法键盘插入洞洞谱 item，制作一份可保存、可打开、可导出的手动洞洞谱。

该模式中：

```text
洞洞谱 items = 源内容
数字谱文本 = 不存在
```

## 2. 适用场景

- 教学者手动排一段指法。
- 用户想记录半孔、叉口、替代指法。
- 用户只关心指法顺序，不关心曲谱调和完整乐理。
- 数字谱自动转换无法覆盖的特殊片段。

## 3. 页面结构

```text
编排洞洞谱

乐谱名称：
[练习曲一________]

配置：
笛子调：[G 调笛]
筒音：[筒音作5]

洞洞谱内容区：
[●●●●●●] [●●●●●○] [●●●●○○] [|]
[●●●○○○] [●●○○○○] [-]

指法键盘：
低音：
[低5] [低6] [低7]

中音：
[1] [2] [3] [4] [5] [6] [7]

高音：
[高1] [高2] [高3] [高4] [高5] [高6] [高7]

符号：
[休止] [延音] [小节线] [换行]

编辑：
[删除] [清空]

当前选中项：
简谱标记：[5]
音高标记：[D5]
备注：[筒音]

操作：
[保存] [导出 JSON] [返回]
```

## 4. 指法键盘

指法键盘来源于：

```text
fluteKey + fingeringProfileId -> buildDiziTargets -> 指法孔位表
```

每个按钮展示：

- 简谱标签
- 洞洞图
- 可选备注

点击按钮后，向内容区插入一个 `HoleNoteItem`。

## 5. 内容区 item

支持：

| 类型 | 说明 |
|---|---|
| `note` | 指法音 |
| `rest` | 休止 |
| `hold` | 延音 |
| `bar` | 小节线 |
| `lineBreak` | 换行 |

第一版支持：

- 插入
- 点击选中
- 删除选中项
- 清空全部
- 编辑选中项的显示名、音高标记、备注

第一版不支持拖拽排序。若用户要调整顺序，可以删除后重新插入。

## 6. 配置切换

切换笛子调或筒音指法时：

1. 指法键盘按新配置刷新。
2. 已经插入的内容区 items 默认保留。
3. 页面设置 `dirty = true`。
4. 可以提示“已插入内容不会自动重算，如需重排请重新插入”。

原因：手动模式中 `holeScore.items` 是源内容，切换配置不应静默改写用户已经编排的孔位。

## 7. 保存规则

保存时写入：

```ts
{
  mode: 'manual-hole-score',
  config: {
    fluteKey,
    fingeringProfileId,
  },
  source: {
    kind: 'manual-hole-score',
  },
  holeScore: {
    items,
  },
}
```

## 8. 非目标

- 不支持拖拽排序。
- 不支持自定义新孔位模板。
- 不支持一音多个替代指法选择。
- 不支持节奏时值编辑。
- 不支持从手动洞洞谱反推数字谱。

## 9. 验收标准

1. 可以选择笛子调和筒音指法。
2. 指法键盘能展示当前配置下的目标音和洞洞图。
3. 点击指法按钮能向内容区插入 note item。
4. 可以插入休止、延音、小节线和换行。
5. 可以选中 item 并编辑显示名、音高标记和备注。
6. 可以删除选中 item。
7. 可以清空全部 items。
8. 保存后乐谱出现在本地乐谱库。
9. 打开已保存手动乐谱后，洞洞谱内容能恢复。
